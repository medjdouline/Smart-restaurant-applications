# Smart Restaurant Applications

Projet de Fin d'Études (PFE) de Licence à l'USTHB (Université des Sciences et de la Technologie Houari Boumediene). Le projet propose des solutions numériques innovantes pour la gestion de restaurant et l'engagement client, dans une optique d'introduction à l'IoT.

## Composants
- `back-end/` — API back-end (responsabilité de l'auteure), incluant un système de recommandation (introduction au ML)
- `flutter_application_1/` — application mobile cliente (Flutter)
- `app_serveur-master/` — application côté serveur/restaurant
- `good_taste-main/` — application complémentaire du projet

## Fonctionnalités
- Gestion des commandes et du menu
- Système de recommandation de plats
- Applications interconnectées (5 modules au total)

## Technologies
- Back-end : Python
- Mobile : Flutter/Dart
